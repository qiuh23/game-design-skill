# 首页范式

目标：手机竖屏不滚动即可开房或进房。先保证常驻入口和可操作空间，再让舞台占大部；视觉参数由各游戏决定。

| 层 | 元素与行为 |
| --- | --- |
| 常驻顶栏 | 左侧返回大厅箭头与品牌，箭头的 `aria-label` 和 `title` 都是「返回游戏大厅」，指向统一大厅。右侧规则、设置等图标；不在图标下写汉字。国内站／海外站只占顶栏一处小字。 |
| 舞台 | 卡坦棋盘、巫师牌烛光桌、运动会角色与主视觉各自保留。舞台占主要面积；单独逐项审视首页控制，不把局内工具照搬过来。 |
| 动作坞 | 紧凑昵称行，换昵称用图标；下方并排的「创建房间／加入房间／单人练习」格子，各用图标和短文案。创建房间唯一主按钮。单人入口承接各自规则；运动会额外的人机对战排在单人练习之后。 |
| 降级区 | 仅有可恢复房间时显示小字恢复链接。提供公开房间的游戏，将人数与折叠列表整合成默认收起的一行；展开后空状态「暂无公开房间」。 |

「加入房间」打开独立弹窗：房间码输入、提交加入。不要在首页原地展开表单。v2 是被替代的历史写法，以 v3 的真机反馈为准。弹窗复用游戏自己的组件，并支持点击遮罩、右上角 ×、Esc 三种关闭方式。局内交互参见[房间外壳](room-chrome.md)。

不要为减少一行去缩小有效触控区。短横屏、键盘弹起与安全区独立检验；首屏目标不能仅凭 CSS 约束或静态截图宣布通过。
