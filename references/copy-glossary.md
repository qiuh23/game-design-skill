# 文案词表

高频操作用以下写法；在需要显示布局标题、图标可访问名称、空状态或动作文本时不换同义词。

| 用途 | 指定文案 |
| --- | --- |
| 开房 | 创建房间 |
| 进朋友的房 | 加入房间 |
| 单人入口 | 单人练习 |
| 规则标题／图标可访问名称 | 玩法规则 |
| 公开房间空状态 | 暂无公开房间 |
| 发送邀请 | 邀请朋友 |
| 房间码按钮 | 复制房间码 |
| 退出当前房间 | 退出房间 |
| 开始游戏 | 开始游戏 |
| 返回统一大厅图标的 aria-label 与 title | 返回游戏大厅 |

文案短、平、口语。诸如「开一桌」的专属说法只用于板块小标题或欢迎语，不作为主入口或唯一标识。「玩法规则」是图标的可访问名称、提示或标题，不要求把汉字放在顶栏图标下。
