# 令牌标尺

每款游戏只在一个 token 源文件定义语义值；`DESIGN.md` 的 frontmatter 表与正文同步。组件只引用源 token，迁移期的纯引用别名不是第二套值。机器可读镜像（如卡坦的 `.impeccable/design.json`）记录相同值，不作为组件的另一数值来源。按语义选档，不按旧散值拼凑。

| 维度 | 家族标尺 |
| --- | --- |
| 字阶 | 11 最弱辅助、12 次级、13 紧凑正文、14 正文、16 强调、18 小标题、20 面板标题、24 页面标题、32 首页主标题，单位 px；真实信息不得小于 11px。流式展示有经确认的基准档，别让几何约束变成小字。 |
| 字重 | 400 / 500 / 600 / 700 / 800。 |
| 圆角 | 8 / 12 / 14 / 999px；圆形用 50%。卡坦的控件／面板别名实际为 8／12px。 |
| 间距 | 4px 基准，通用档位 4 / 8 / 12 / 16 / 24 / 32px。棋盘、卡牌等场景几何不套用 UI 间距。 |
| 阴影 | 三档：静置卡片、悬浮面板／下拉、弹窗。同一层用同一个 token；招牌阴影单独声明，例如运动会主控件硬阴影、巫师牌烛光效果。 |
| 层级 | 0 基础 / 10 粘性栏 / 20 对局坞 / 30 横幅与气泡 / 40 菜单 / 50 弹窗 / 60 toast。 |
| 动效 | 120ms 微反馈 / 180ms 常规 / 240ms 面板进出，缓动 `cubic-bezier(.2,.7,.3,1)`；系统要求减少动态时，从源把这三档置为 0ms。此标尺约束 UI 反馈，不把画面、镜头和游戏演出裁成通用毫秒数。 |
| 焦点 | `3px solid var(--ui-focus)` 与 `outline-offset: 3px`；各游戏决定本身的焦点颜色。 |
| 触控 | 宽、高均不小于 44px；视觉可以偏小，但用 padding 或伪元素补热区，不能覆盖邻近控件。 |
| 断点 | 按实际布局少量归并；桌面、竖屏、短横屏与安全区分别检查。不是全家硬用同一个断点。 |

家族数值来源：《UI改造指令-给GPT》「目标设计尺度」、2026-11-16《设计Skill仓库指令》及当前[卡坦设计文档](https://github.com/qiuh23/catan-friends/blob/68694c287189e1984ddeca61e9df9c79e0f43236/DESIGN.md)与[机器可读镜像](https://github.com/qiuh23/catan-friends/blob/68694c287189e1984ddeca61e9df9c79e0f43236/.impeccable/design.json)。前者的卡坦旧阶段段落写 160ms 和 10px 下限，后续指令及已上线同步规范是 180ms 与 11px；按新版，不将旧值写成当前规范。

## 颜色：按用途，不按总数

文字、表面、控件、边框、强调、焦点和状态反馈是 UI 语义色：一义一值，全部进 token；透明层从 token 派生，具场景语义的别名可引用同一值。卡面、烛光、渐变、3D 光照等装饰和特效色按表现需要，不限数、不充当实际语义。不能把选择态、焦点等改名成「特效」就绕开。旧任务的总体色数比例或巫师牌 ≤200 目标不是现行红线，按最新的语义／装饰裁决。
