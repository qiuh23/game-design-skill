# 平台与版本

| 站点 | 发布 | 域名 |
| --- | --- | --- |
| 国内站 | 阿里云 | `*.magical-athlete-online.cn`（运动会入口还使用根域名） |
| 海外站 | Cloudflare | `*.qiuh23.workers.dev` |

- 从新游戏第一天接入构建标记 `SITE_EDITION=cn/global` 与版本策略；依各游戏真实实现处理昵称、聊天和房间码等分流。海外可有聊天、国内没有；C-/A- 是家族现有分流示例，不用 CSS 去决定业务策略。
- 每次视觉发布分别构建国内和海外版本，核对各自部署的确切版本、入口和房间连接。别把一个站点构建成功当成双站上线。
- 在统一大厅登记两站的路由及线路配置，验证从大厅进入正确站点，并从各游戏的「返回游戏大厅」回到同线路大厅。游戏独立部署，不需要跨仓共享代码。大厅自身视觉与游戏身份不是一套皮肤。
