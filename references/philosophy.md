# 设计哲学与品味判例

共享流程结构、控件位置、操作方式和文案；独立保留配色、字体、主视觉、动效性格和招牌展示。判断尺度是「换游戏不用重找入口」和「一眼能认出游戏」。范式从 Qiu 已真机验收的运动会、卡坦岛实现提炼；不从尚未确认的版本倒推标准。

| 裁决 | 来由 |
| --- | --- |
| 简洁度看卡坦岛：一屏、一个动作区，不做落地页长菜单。 | 已验收的卡坦首页直接在棋盘舞台上承载入口。 |
| 舞台占首页大部分，按钮区做配角。 | 巫师牌 v2 的牌桌被挤在上方，v3 要求恢复舞台主体。 |
| 主动作并排成格，不铺三个整宽大横条。 | 巫师牌实际验收明确否决整宽三横条。 |
| 「加入房间」是独立按钮，房间码在弹窗填。 | v3 否决 v2 的首页内嵌表单；这条以真机反馈后的裁决为准。 |
| 首页只留真正有用的舞台控制。 | 卡坦 v3 只保留 2D/3D，移除暂停和复位，但不关闭默认展示动画或修改局内工具。 |
| 顶栏图标按钮只显示图标，文字放在可访问名称、提示或弹窗标题。 | 运动会规则按钮被加汉字标签后破坏了顶栏，整轮对齐回退。 |
| 专属说法可做板块小标题，不代替主动作。 | 卡坦「开一桌」可保留氛围，统一主按钮仍用「创建房间」；现网若尚未改，记为差距。 |
| 次要信息降级或收起。 | 巫师牌 #56 经真机反馈认可：线路为顶栏小字、恢复为小字链接、在线房间默认收起。 |
| 返回大厅和退出房间永不合并，返回大厅只有一个顶栏箭头。 | 巫师牌 #56 已将大按钮与重复入口收拢；房内确认仍不等于退出房间。 |
